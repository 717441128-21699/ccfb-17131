# 一箱皮影走村乡

一个老皮影戏班经营模拟游戏。玩家当班主，带着签手、上手、下手、胡琴、锣鼓和学徒，挑一副戏箱走渭北旱塬、洛河川道、黄龙山东三片乡土，赶庙会、唱还愿、修影人、拜师学戏、应付雨雪和别的戏班，最后封箱算账，看能不能过个好年。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可。

生产构建：

```bash
npm run build
npm run preview
```

## 已实现的规矩

- **Canvas 地图巡演**：15 个虚构村子、22 条村路、三片区域；地图上绘制村路里数和行程、庙会日期、玩家“班”字令牌、其他戏班位置与行进动画。
- **路程规则**：只能去相邻村，不能跳村；脚程按 `35 里/日` 向上取整，近路一日，远邻两日程。
- **村子需求**：每村有人口、人户、收成、庙会日期/庙会名、戏台类型和戏码偏好；秋收后有谢秋戏，平时有还愿戏。
- **口味衰减与恢复**：同一出戏近期唱得越多，本村喜欢程度下降越重；75 日内的场次计入“听腻”，间隔越久恢复越多。
- **排戏与演出成色**：成色由五行技艺、排戏熟度、本村口味、戏本号召力、影人状态、人马状态、天气和对台结果共同决定。
- **人员与股份**：签手、上手、下手、胡琴、锣鼓、学徒各有股份、技艺、健康、气力、忠诚和场次；每夜戏钱加赏钱提 38% 按股滚存，年下兑现。生病、被挖角会导致核心行当缺人，可请医、犒赏、借钱或张榜雇人。
- **戏箱与唱本**：9 类影人/切末有数量和完好度，会随演出磨损，可整修或新添；9 本戏各有行当/影人要求，其中 5 本要到指定村子拜师，学后还可排演。
- **天气与竞争**：晴、多云、阴、小雨、连阴雨、雪、西北风按季节生成，页面提供后三日预报；坏天气会回戏并赔偿。三个 rival 戏班会沿村路移动、赶庙会，并可能与玩家唱对台、挖人。
- **年终账本**：每笔戏钱、赏钱、管饭折银都关联具体演出；账本里点击带“点开查场”的进项，可查看年份日期、村、会首名目、第几夜、戏码、天气、看客、成色因子、对台、口味变化和每人本场滚存股份。封箱时先还外债本利，再按股发钱，给出“红火大年 / 体面过年 / 紧巴年关 / 散班难关”。
- **本地存档**：状态自动存入 `localStorage`；账本页可重新开班。

## 目录

```text
src/
  data.ts       村子、路线、戏本、影人行当、初始班底和 rival 数据
  types.ts      全部游戏状态与账本/演出类型
  engine.ts     日历天气、行程、合同、演出推演、事件、股份和年结
  mapCanvas.ts  Canvas 地图、点选、标记和行进动画
  ui.ts         四个页面与各类弹窗的 DOM 模板
  main.ts       事件接线、本地存档、弹窗控制
  styles.css    旧纸/木台/账本视觉与响应式布局
scripts/
  smoke.ts      引擎规则与账目穿透冒烟模拟
  balance.ts    理性赶场策略的经济平衡模拟
  browser-check.mjs  Chrome DevTools Protocol 交互检查
```

## 检查

```bash
npm run build
node scripts/browser-check.mjs
```

`browser-check.mjs` 默认访问 `http://127.0.0.1:4180/`；可先运行 `npm run preview -- --port 4180`。
