# 一棚灯影 · 老皮影戏班经营

一个以老皮影戏班走村串乡为题材的经营游戏。玩家当班主，带着签手、上手、下手、胡琴、锣鼓和学徒，以一副戏箱在“北蟒塬、渭河川、南山坳”三片地方赶庙会、排戏、赶路、修影人、拜师学戏、应付雨天和同行挖角，年底按老规矩的股份算账。

## 运行

```powershell
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://127.0.0.1:5173/`）。

生产构建：

```powershell
npm run build
npm run preview
```

构建会先执行 `tsc --noEmit`，再由 Vite 打包到 `dist/`。

## 页面

- **地图巡演**：Canvas 绘制三片乡域、16 个虚构村子、村路里数、庙会标记、同行戏班和“班”字行进位置；右侧查看村情、邻村路程、未来天气、排戏预期并开戏。
- **戏班人员**：查看签手、上手、下手、胡琴、锣鼓、学徒的手艺、健康、忠心和股份；可抓药、赏钱、请把式或收学徒。
- **戏箱唱本**：八堂影人的件数/成色/修理/新添，十二本戏的要求、擅长地域、拜师师父、学费和学期。
- **年终账本**：全年收入、花销、股份分红和最终箱底；每一笔进项都能点开核查是哪个村、哪一张合约、哪一天、天气、观众数、成色和赏钱。

进度会自动存入浏览器 `localStorage`，顶栏可“重开一班”。

## 核心规矩与代码位置

所有经营推演均为框架无关的 TypeScript，不依赖 Canvas 或 DOM：

- `src/game/types.ts`：状态、人员、村子、账目、场次、年终结算等类型。
- `src/game/data.ts`：16 个村子、庙会日子、村路里数、12 出戏、影人、人员、同行戏班等虚构数据。
- `src/game/world.ts`：邻村、路径、按里数计算日程、行当齐备度、影人齐备度、村子对剧目的基础偏好。
- `src/game/simulation.ts`：喜好、演出成色、观众、戏钱、彩钱、庙会赏银和收入预估。
- `src/game/engine.ts`：一日推进、赶路、演出、天气、疾病、挖角、拜师、修理、雇人、记账、股份和年终结算。
- `src/ui/mapCanvas.ts`：Canvas 地图、路径、村子、庙会/同行标记和戏班移动动画。
- `src/ui/render.ts` / `src/main.ts`：四个页面、弹窗、事件和存档。

### 几条明确模拟规则

1. **听戏喜好衰减与恢复**：每村对每出戏有独立喜好值。近期每唱一次，喜好下降；35 天内重复会追加“听腻”惩罚。不唱时，喜好按天数向该村的基础偏好恢复，隔得越久恢复越多。
2. **路程按里数算**：戏箱车约日行 30 里，`ceil(路程里数 / 30)` 得出行天数；只能沿 `ROUTES` 中的邻村移动，不允许一步跳到非邻村。
3. **庙会与村情**：每村有固定农历庙会、人口、收成、富庶度和剧目标签偏好；庙会窗口提高观众和赏银。
4. **人员行当**：五类核心行当必须有人能应活。正式把式病倒或离班后，只有会顶替的学徒/副手能补，且有手艺惩罚；否则相关剧目不能开唱。
5. **戏箱与唱本**：剧目明确要求影人行头；演出磨损成色，低成色降低质量。未拥有的唱本必须付学费并占用若干天拜师学习。
6. **同行与意外**：三个同行戏班会转场并在同村分流观众；忠心低的成员可能被挖角，玩家可花钱挽留、讲情或放行。
7. **雨天赔偿**：天气按农历月份生成，未来七日可预报。雨/雪天皮影不能演，当日所有进项归零，并支出一笔“雨灾赔偿”。
8. **股份年终账**：班主戏箱与公中占 45 股，在场成员按身股占其余股份。年终净余按股分派，每笔分红也入账；最终箱底和名声决定年景评级。

## 内容说明

地名、会首、师父、戏班、年份和数值均为游戏化虚构/综合设计，用来承载可推演的经营规则，不对应具体个人或精确地方史。
